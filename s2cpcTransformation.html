CPC Transformation¶

Kevin Kam Fung YUEN

This notebook presents a data transformation workflow that applies Cognitive Pairwise Comparisons (CPC) to discretize continuous features within a movie ratings dataset. It demonstrates how to systematically convert numerical variables—such as release years, average rating scores, and rater sizes—into meaningful categorical intervals using pairwise comparison matrices. Finally, the notebook performs one-hot encoding on these newly generated categories and restructures the dataset for export and downstream analysis.
