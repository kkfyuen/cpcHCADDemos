Classification with CPC¶

Kevin Kam Fung YUEN

This notebook presents a CPC-weighted decision-making framework to systematically evaluate and select learning models for classifying movie rating grades. Seven machine learning algorithms are benchmarked across 10-fold cross-validation using multiple performance metrics, including accuracy, macro-precision, macro-NPV, macro-recall, and macro-specificity. By integrating Cognitive Pairwise Comparisons to weigh these evaluation criteria, the notebook ranks candidate classifiers to determine the optimal model for final predictions.
