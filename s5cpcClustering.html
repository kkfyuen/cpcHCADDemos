Clustering with CPC¶

Kevin Kam Fung YUEN

This notebook presents a sophisticated clustering framework that integrates Cognitive Pairwise Comparisons (CPC) to enhance movie recommendation systems. It systematically models user preferences by calculating subjective weights for key movie features and genres using pairwise comparison matrices. These CPC-derived weights are then incorporated into Principal Component Analysis (PCA) for optimized data reduction before applying K-Means clustering. Finally, the workflow determines the optimal cluster size, evaluates cluster validity using silhouette metrics, and identifies the top-performing movie groups to drive targeted recommendations.
