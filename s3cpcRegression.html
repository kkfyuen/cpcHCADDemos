Regression with CPC¶

Kevin Kam Fung YUEN

This notebook establishes a CPC-guided linear regression workflow to predict movie ratings using transformed dataset features. It utilizes Cognitive Pairwise Comparison matrices to determine feature preference weights, which directly drive data partitioning across training, validation, and test sets as well as MSE-based forward feature selection. The final output evaluates regression performance across splits, generates feature selection trajectory plots, and exports formatted result tables for downstream analysis.
